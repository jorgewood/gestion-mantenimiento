# Gestión de Mantenimiento - Colegio

Sistema para la gestión de solicitudes de mantenimiento y eventos escolares.

## 🚀 Características

- 📝 Creación de solicitudes de mantenimiento y eventos
- 🔐 Autenticación de usuarios (Sección, Proyectos Generales, Mantenimiento)
- 📋 Bandeja de Proyectos Generales para autorizar/rechazar
- 🔧 Panel de Mantenimiento para gestionar solicitudes
- 📱 Envío de notificaciones por WhatsApp
- 🖼️ Logo personalizable
- 💾 Respaldos y restauración de datos

## 📦 Tecnologías

- **Frontend**: HTML, TailwindCSS, JavaScript
- **Backend**: Node.js, Express
- **Almacenamiento**: Archivo JSON
